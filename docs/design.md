# 已确认的产品规则

项目名：**saunagent**。一个个人 room 承接所有工作，第一版采用命令行 TUI：左侧任务 agent，右侧统一 room。

## 任务与消息

- 按目标和完成条件划分任务；独立目标创建新 agent，未解决的原目标继续原 agent。
- Agent 只接收分配给自己的输入，可按需检索 room 历史；主管查看全局任务目录和进展。
- 主管只选择目标或创建任务，转交用户原文，独立附带消息、任务、引用、目录等上下文信息。
- `@`、引用回复直接定位目标；多个合理候选时请求澄清。
- 选中任务后右侧立即显示该 agent 的对话流，无需打开详情；输入框明确显示目标。切回全部恢复完整 room 和自动路由。Ctrl+D 仅用于可选查看任务元信息、工具和执行记录。
- 默认排队后续输入；明确暂停、改方向或优先处理的要求介入当前工作。
- 新任务立即执行，多行输入允许用户一次提交完整要求。
- room 展示关键进展、待回答问题和结果；工具和日志放在任务详情。

## 执行与生命周期

- 默认 3 个任务并发，可配置；等待用户时释放名额，内部 subagent 另设总上限。
- 同目录允许并行读取，修改和测试按任务排队；不同目录可以并行。首版暂用整轮串行实现同目录协调。
- 任务 agent 自行创建和管理内部 subagent，不展示为顶层任务，不与用户直接交流。
- 任务关联项目与目录；目标唯一时自动关联，否则澄清，非代码任务可以不绑定。
- 默认工作模型、主管模型分别配置，任务允许覆盖；失败保留状态，手动重试或切换。
- 公共配置提供工具与 skills，项目可追加指令与 skills。沿用 Pi 默认工具执行策略，并遵守项目指令。
- 本轮结束、等待反馈和验收完成分别表示；需要用户验收的工作不能自动标记已完成。收起只影响显示。
- 纠正路由时停止原任务对此消息的处理，转交原文并保留记录，明确已发生操作及可能需要的撤销。
- 退出 TUI 时停止新操作，允许当前工具完成，保存后退出。支持强制退出。重开后保持暂停，手动继续。
- 第一版不含定时唤醒。

## 第一版核心验收

1. room 提出任务 A，主管创建 A，原文不变地转交。
2. A 工作期间提出独立任务 B，B 并行运行。
3. 补充 A 的要求，系统定位 A；存在歧义时先澄清。
4. 左侧选择或 `@` 直接与指定任务交流。
5. 退出时当前工具完成并保存；重开恢复消息、任务和队列，任务保持暂停。
6. 手动继续 A，沿用退出前上下文完成工作。

## 技术基线

Pi coding agent `1.4.0`（`createAgentSession` / `AgentSession` / `SessionManager`）、Pi AI、Node SQLite（仅 room 历史摘要）；React + Ink 实现 TUI。每个任务一个 JSONL 会话，room 投递记录用 `saunagent.delivery` 自定义条目标记。恢复时继续未完成会话，答案按会话 leaf entry ID 去重。主管和历史总结是一次性内存会话。

和 Pi Durable 的差异：没有提交重放；优雅退出会等已开始的工具结束，但崩溃在工具结果写入前不能重放该工具；aborted 助手消息在恢复时从模型上下文省略后再继续；内部 subagent 不单独落盘；同轮 steer 与原投递可能共用一个答案 ID。自动 compaction 与 cache warming 关闭。旧的 `*.sqlite` harness 文件不再使用。

官方依据：[Pi SDK](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/sdk.md)。实现以安装版本的实际导出与类型为准。
